Xây dựng giao diện Web A bằng ReactXây dựng Web A bằng React với giao diện Nhịp Workspace, hỗ trợ máy tính và điện thoại. Ứng dụng hiển thị hồ sơ, vai trò, chấm công cá nhân và các chức năng theo quyền. Menu được điều chỉnh theo tài khoản; mọi yêu cầu API vẫn phải được backend kiểm tra độc lập. Token được sử dụng trong bộ nhớ phiên của keycloak-js, không đưa vào ảnh minh chứng.
