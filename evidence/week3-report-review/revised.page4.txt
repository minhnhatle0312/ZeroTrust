Xây dựng Backend API và phân quyền RBACBackend Node.js/Express nhận Bearer Token và dùng thư viện jose xác minh chữ ký RS256 bằng JWKS của Keycloak; kiểm tra issuer, audience, thời hạn và các claim bắt buộc sub, iat, exp. Danh tính sub được đối chiếu với hồ sơ nhân viên phía server; vai trò trong JWT phải khớp vai trò của hồ sơ. Cơ chế này áp dụng trước khi xử lý các API /api/profile, /api/manager, /api/admin và /api/audit.Quy tắc RBAC: các tài khoản đã được cấp hồ sơ và vai trò hợp lệ đều được đọc /api/profile; manager và admin được đọc /api/manager; chỉ admin được đọc /api/admin; admin và auditor được đọc /api/audit. Kết quả: API từ chối thiếu token bằng HTTP 401 và từ chối sai quyền bằng HTTP 403; kết quả đối chiếu được trình bày tại mục 2.5.
