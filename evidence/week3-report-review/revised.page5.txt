2.5. Kiểm thử xác thực và phân quyềnĐăng nhập lần lượt bằng bốn tài khoản demo qua Keycloak thật và gọi bốn API để đối chiếu 16 kết quả với ma trận RBAC. HTTP 200 xác nhận yêu cầu có token hợp lệ và đủ quyền. Khi không gửi token đến /api/profile, backend trả HTTP 401, status DENY và code MISSING_TOKEN. Khi employee01 gọi /api/admin bằng token hợp lệ, backend trả HTTP 403 với code INSUFFICIENT_ROLE. Các phản hồi được lưu trong verification.json, không lưu token hoặc mật khẩu.Kết quả kiểm chứng ngày 01/11/2026: toàn bộ 16 yêu cầu theo vai trò trả đúng HTTP 200/403; trường hợp thiếu token trả đúng HTTP 401. Chạy npm.cmd test trong backend đạt 54/54 bài kiểm thử, không có bài thất bại. Bộ backend sử dụng khóa JWT kiểm thử riêng, SQLite riêng và mô phỏng tương tác Keycloak; kết quả này được phân biệt với kiểm thử tích hợp Keycloak thật ở Hình 2.5./Hình 2.5.
