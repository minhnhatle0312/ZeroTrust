Kiểm soát đăng xuất và triển khai HTTPS LAN/VPNBackend đối chiếu sid trong token với phiên Keycloak thật, cache tối đa 5 giây; frontend kiểm tra phiên mỗi 15 giây và khi nhận focus. Khi đăng xuất một ứng dụng, ứng dụng còn lại phát hiện phiên kết thúc; API từ chối token cũ dù chưa hết hạn. Nếu không kết nối được Keycloak để kiểm tra phiên, API trả HTTP 503.Triển khai HTTPS gateway cho Web A tại /a/, Web B tại /b/, API và endpoint xác thực qua một địa chỉ LAN/VPN. Backend kết nối Keycloak qua loopback; issuer khớp URL HTTPS công khai. Đã kiểm tra chuỗi chứng chỉ, IP SAN và chặn đường dẫn riêng tư; máy thứ hai truy cập được HTTPS nhưng chưa xác nhận tin cậy CA và đăng nhập.
